# ChatPDF Android — پروژهٔ اولیهٔ نسخهٔ اندروید

این پروژه بازسازی اندرویدی برنامهٔ Tkinter است؛ کد دسکتاپ را نمی‌توان مستقیماً به APK تبدیل کرد.

## قابلیت‌های پیاده‌سازی‌شده
- انتخاب PDF از حافظهٔ دستگاه
- نمایش صفحه و جابه‌جایی بین صفحات
- استخراج متن PDF (برای PDFهای اسکن‌شده، OCR در این نسخه وجود ندارد)
- انتخاب زمینهٔ «صفحه»، «کل کتاب» یا واردکردن/چسباندن متن انتخاب‌شده
- توضیح متن با AI و پرسش‌وپاسخ مبتنی بر متن
- آزمون چهارگزینه‌ای، امتیازدهی و ذخیره/بازکردن آزمون‌ها
- خواندن صفحه و پاسخ با موتور Text-to-Speech اندروید

## نیازمندی‌ها
- Android Studio (نسخهٔ پایدار جدید)
- JDK 17
- Android SDK Platform 35 و Android Build Tools
- اتصال اینترنت برای Gradle و سرویس AI

## ساخت APK با Android Studio
1. فایل ZIP را استخراج کنید.
2. Android Studio را باز کنید و `Open` را بزنید؛ پوشهٔ `ChatPDF_Android` را انتخاب کنید.
3. صبر کنید Gradle Sync و دریافت dependencyها تمام شود.
4. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** استفاده کنید.
5. پس از موفقیت، روی **locate** کلیک کنید. معمولاً فایل اینجاست:
   `app/build/outputs/apk/debug/app-debug.apk`
6. APK را به گوشی منتقل و نصب کنید. برای نصب خارج از Play Store ممکن است لازم باشد اجازهٔ نصب از این منبع را فعال کنید.

## ساخت از ترمینال
در پوشهٔ پروژه (پس از نصب Android Studio/SDK) اجرا کنید:
```bash
gradle assembleDebug
```
اگر Gradle نصب نیست، بهتر است Android Studio را باز کنید و از Gradle wrapper بسازید، یا از گزینهٔ Build APK در رابط کاربری استفاده کنید. این ZIP عمداً wrapper binary را شامل نمی‌شود.

## تنظیم سرویس AI
نسخهٔ دسکتاپ از endpoint عمومی `https://text.pollinations.ai/openai` استفاده می‌کرد. اپ اندروید نیز برای حفظ رفتار مشابه همین endpoint را فراخوانی می‌کند. این سرویس شخص ثالث است؛ دسترس‌پذیری، مدل، محدودیت مصرف و سیاست حریم خصوصی آن ممکن است تغییر کند. متن PDF یا سؤال‌هایی که می‌فرستید برای تولید پاسخ به سرویس ارسال می‌شود. از ارسال اسناد حساس خودداری کنید.
در نسخهٔ تولیدی، endpoint و کلید API را از تنظیمات قابل‌تغییر کنید و کلید محرمانه را داخل APK قرار ندهید.

## محدودیت‌های مهم نسخهٔ اولیه
- برای متن «انتخاب‌شده»، متن را در کادر بچسبانید؛ انتخاب مستقیم متن با لمس روی تصویر PDF هنوز پیاده‌سازی نشده است.
- OCR برای PDF اسکن‌شده وجود ندارد.
- استخراج متن صفحه بر اساس جداکننده‌های متداول PDF انجام می‌شود و ممکن است در برخی فایل‌ها صفحه‌بندی متن دقیق نباشد.
- جست‌وجوی پیشرفته در کل کتاب و خلاصه‌سازی چندمرحله‌ای، مثل نسخهٔ دسکتاپ، در این نسخهٔ اولیه کامل نشده است.
- رابط کاربری فارسی است، اما ممکن است در برخی دستگاه‌ها نیاز به تنظیمات بیشتر راست‌به‌چپ داشته باشد.
- این پروژه در محیط فعلی با Android SDK/Gradle قابل build نبود؛ بنابراین APK کامپایل‌شده و تست‌شده ادعا نمی‌شود. قبل از انتشار، روی دستگاه واقعی تست کنید.

## رفع خطاهای معمول
- اگر Gradle Sync شکست خورد: بررسی اینترنت، JDK 17 و Android SDK Platform 35.
- اگر سرویس AI خطا داد: endpoint ممکن است موقتاً در دسترس نباشد؛ متن خطا در خروجی برنامه نشان داده می‌شود.
- اگر PDF تصویر اسکن‌شده است: استخراج متن خالی می‌شود؛ OCR باید به پروژه اضافه شود.

## ساخت فقط با گوشی از طریق GitHub Actions
این پروژه فایل workflow آماده در `.github/workflows/build-apk.yml` دارد.
1. در مرورگر گوشی وارد GitHub شوید و یک مخزن جدید (Repository) بسازید.
2. فایل‌های داخل پوشهٔ پروژه را در مخزن قرار دهید؛ ساختار پوشه‌ها را حفظ کنید، به‌خصوص `.github/workflows/build-apk.yml`.
3. در مخزن، زبانهٔ **Actions** را باز کنید و workflow با نام **Build ChatPDF APK** را انتخاب کنید.
4. گزینهٔ **Run workflow** را بزنید. پس از اتمام، اگر مرحله‌ها سبز شدند، وارد اجرای انجام‌شده شوید و از بخش **Artifacts** فایل `ChatPDF-debug-APK` را دانلود کنید.
5. ZIP artifact را در گوشی استخراج کنید؛ فایل `app-debug.apk` را باز کنید و نصب را تأیید کنید.
اگر مخزن تازه ساخته شده است، ممکن است لازم باشد Actions را فعال کنید. فایل workflow با هر push به شاخهٔ main نیز اجرا می‌شود.


## به‌روزرسانی رابط کاربری
نسخهٔ فعلی با تم تیرهٔ سرمه‌ای، رنگ تأکیدی نارنجی، پنل‌های گرد و بخش‌بندی واضح‌تر برای کتابخانه، ابزارهای مطالعه، گفت‌وگو و پاسخ AI تنظیم شده است. این تغییر ظاهر را به نمونهٔ موبایلی نزدیک‌تر می‌کند، اما هنوز لازم است روی دستگاه اجرا و تست شود.
